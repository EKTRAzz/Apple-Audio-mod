แชนเนล, 8,400 samples ครบไม่ตัดหาง) พร้อมระบบ Single-Winner Multi-Pipeline Hook เพื่อจับท่อเสียงหลักของแอปโดย ไม่ทับไลน์กันจุดเด่นหลักตรงกับ HeSuVi บน PC มากที่สุดใช้สูตร matrix.txt + 14-channel convolution (hesuvi.txt) + mix.txt ของ HeSuVi PC แท้ๆ ยุบรวมเชิงเส้นเป็น True-Stereo 4 แชนเนล (LL, LR, RL, RR) ด้วยความคลาดเคลื่อนระดับ 1e-7เก็บความยาว Impulse Response ครบทั้ง 8,400 samples (0.175 วินาที ไม่ตัดปลายหางที่ 8192) บน FFT_N = 16384 แบบ Zero-Added-Latency Overlap-Save ผ่าน Accelerate (vDSP_fft_zrip)แก้การคูณ Bin 0 (DC/Nyquist) ของ vDSP_fft_zrip แยกต่างหาก และตั้งค่า Headroom เริ่มต้นที่ -2.5 dB (รองรับ peak สูงสุด +2.41 dB ของ IR โดยไม่ลดความดังจนเบากว่า PC พร้อม Soft Clipper tanhf เหนือ ±0.985)สร้างได้ 2 โหมด:SpatialDSP_ApplePro2_Matrix.dylib: โหมด Matrix Upmix (ตรงกับ การใช้งานกับ YouTube Music iOSแอป YouTube Music บน iOS ใช้เอนจินเล่นสื่อของ Google (MLHAMPlayer / MLHAMQueuePlayer) ร่วมกับ MLAVPlayer (YouTubeHeader, Apps RE) ซึ่งรองรับ Sample Rate หลักที่ 48 kHz (Opus) และ 44.1 kHz (AAC) ตรงกับที่ SpatialEngine ประมวลผลได้วิธีติดตั้ง (Inject .dylib)เลือกไฟล์ .dylib ที่ต้องการเพียง 1 ไฟล์ (SpatialDSP_ApplePro2_Matrix.dylib หรือ SpatialDSP_ApplePro2_Front.dylib)นำไป Inject เข้าไฟล์ .ipa ของ YouTube Music ด้วยเครื่องมือ Sideload/Sign ที่รองรับ (เช่น Sideloadly, ESign, Feather หรือ LiveContainer) หรือติดตั้งผ่านเครื่อง Jailbreakต่อ หูฟังมีสาย, Bluetooth (A2DP/LE) หรือ USB DAC แล้วเปิดเพลงทดสอบ (หากฟังผ่านลำโพงเครื่อง ระบบจะ Bypass อัตโนมัติ)เงื่อนไขที่อาจทำให้ระบบ Bypass บน YouTube Music iOSกรณีสาเหตุในโค้ดปัจจุบันพฤติกรรมที่เกิดขึ้นไม่ได้ต่อหูฟังRouteMonitor อนุญาตเฉพาะหูฟังมีสาย, Bluetooth A2DP/LE และ USB DACปล่อยเสียงผ่านปกติ (Bypass)แอปส่งเสียงผ่าน AVSampleBufferAudioRendererยังไม่มี Hook สำหรับ AVSampleBufferAudioRenderer ในเวอร์ชันนี้ปล่อยเสียงผ่านปกติ (Bypass)ส่งเสียงบีบอัด (Compressed AAC) เข้า AudioQueueHookAudioQueue ประมวลผลเฉพาะ Linear PCM แบบ Interleaved (inNumPacketDescs == 0)ปล่อยเสียงผ่านปกติ (Bypass)เล่นผ่าน AVPlayer ที่มี audioMix เดิม หรือติด DRMHookAVPlayer ข้ามรายการที่ item.audioMix != nil หรือ hasProtectedContent == YESปล่อยเสียงผ่านปกติ เพื่อกันแอปแครชหรือเสียงเงียบสตรีมไม่ใช่ Stereo 2 แชนเนล หรือ Sample Rate อื่นSpatialEngine รองรับเฉพาะ Stereo 2 แชนเนล ที่ 44.1 kHz และ 48 kHzปล่อยเสียงผ่านปกติ (Bypass)ข้อจำกัดของ iOS Sandboxสตรีมเสียงที่เข้ารหัส FairPlay DRM (เช่น Apple Music DRM, Netflix DRM), เสียงใน WKWebView (รันแยกโปรเซส), และ Compressed AudioQueue ที่ส่งไปถอดรหัสใน mediaserverd จะถูกปล่อยผ่านตามปกติเพื่อไม่ให้เสียงเงียบหรือแอปแครช
